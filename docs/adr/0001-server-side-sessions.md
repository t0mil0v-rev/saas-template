# ADR 0001: серверные сессии

Статус: принято, 2026-08-14.

## Контекст

Браузерному приложению нужны немедленный logout, список устройств, отзыв всех
сессий при смене пароля и блокировка пользователя.

## Решение

Клиент получает случайный opaque token в HttpOnly cookie. PostgreSQL хранит
SHA-256 token, срок, последнее использование и момент отзыва. CSRF token
подписан и привязан к хешу сессии.

## Последствия

Отзыв действует сразу и не требует denylist для JWT. Каждый authenticated
request читает PostgreSQL; масштабирование требует доступной общей БД. Cookie
не подходит внешним API-клиентам без отдельной схемы аутентификации.
