# ADR 0002: граница tenant

Статус: принято, 2026-08-14.

## Контекст

Ошибка фильтрации по организации приводит к утечке между клиентами. Одной
проверки в React или начале HTTP-запроса недостаточно при конкурентной смене
роли.

## Решение

Tenant-доступ требует явного `org_members`. FastAPI dependency скрывает чужую
организацию ответом 404. Изменяющий сервис блокирует строку организации и снова
читает роль. Deferred PostgreSQL triggers требуют активного владельца в
конечном состоянии транзакции. Суперпользователь не получает tenant-role без
membership.

## Последствия

Операции состава одной организации сериализуются. Прямой SQL также сохраняет
владельца, пока triggers включены. Чтения всё ещё обязаны явно фильтровать
`org_id`; PostgreSQL RLS не используется.
