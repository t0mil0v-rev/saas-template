# Политика комментариев

Основной язык комментариев и документации в этом репозитории русский. Имена
модулей, типов, функций, полей и протоколов остаются английскими.

Комментарий нужен, когда без него нельзя быстро понять причину решения:

- инвариант безопасности или транзакции;
- поведение при гонке, сигнале или частичном отказе;
- ограничение внешнего протокола;
- намеренное отклонение от очевидной реализации;
- временный компромисс с условием удаления.

Не нужно пересказывать следующую строку, украшать файл рамкой из символов,
объяснять общеизвестный синтаксис или писать рекламный текст. Комментарий должен
оставаться верным после рефакторинга. Если он описывает контракт, который можно
проверить, рядом нужен тест.

Хороший пример:

```python
# Повторно читаем роль после org row lock: контекст запроса мог устареть,
# пока конкурентная транзакция меняла состав участников.
role = await self._locked_member_role(org.id, actor.id)
```

Плохой пример:

```python
# Получаем роль пользователя.
role = await self._locked_member_role(org.id, actor.id)
```

Docstring описывает публичный контракт, исключения или нетривиальную гарантию.
Для короткой внутренней функции очевидная docstring не обязательна. В тексте
используется обычный дефис `-`; декоративные длинные тире не применяются.
